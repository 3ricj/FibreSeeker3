# Tools

Community tools and handy tricks for working with the FibreSeeker 3.

> **Note:** Third-party tools are listed for convenience — they are not officially endorsed. Use judgment when uploading print files to external sites.

## 🛠️ G-code Inspector

**[Vilos G-code Inspector](http://vilos.com/fibreseeker3gcode/)**

A web-based tool for inspecting G-code generated for the FibreSeeker 3. Useful for looking under the hood of a slice — checking what the machine will actually do, verifying slicer settings took effect, and digging into the details when diagnosing print problems.

Need to know what's actually in FibreSeeker G-code? See the [G-code Reference](GCODE_REFERENCE.md) for the Rocket Slicer's custom axes (`U`/`V`), M-codes, and layer-marker quirks.

## 🖥️ The Printer's Hidden Web Homepage

**http://anisoprint/**

Your printer runs a web homepage packed with helpful information that most owners never see. To reach it:

1. Connect your computer or phone to the **same LAN** as the printer.
2. Type `http://anisoprint/` into a browser.

The hostname resolves to the printer on the local network — no need to remember its IP address. If the name doesn't resolve on your network, check the printer's IP on its touchscreen and browse to that instead.
