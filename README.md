# FibreSeeker 3 — Unofficial Bug Tracker & Knowledge Base

> **Disclaimer:** This is a community-run, **unofficial** repository. It is **not affiliated with, endorsed by, or maintained by FibreSeeker** or its distributors. All trademarks belong to their respective owners.

This repository serves as a central hub for the **FibreSeeker 3** printer community — a place to report bugs, share fixes, and collect troubleshooting knowledge that isn't always easy to find.

## 🐛 Reporting Issues

Found a bug or something weird with your machine? Open an [issue](../../issues) with:

- **Firmware version** (e.g., `2.2.42.831.320`)
- **What you were doing** when the problem occurred
- **Expected vs. actual behavior**
- **Photos / videos** if applicable

## 📚 Documentation

The [`Documentation/`](Documentation/) folder collects official manuals and maintenance guides, including:

- [FibreSeeker 3 Quick Start Guide](Documentation/FibreSeeker%203%20Quick%20Start%20Guide.pdf)
- [FibreSeeker Manual](Documentation/Fibreseeker%20Manual%201_Sep_2026.pdf)
- [Rocket Slicer Quick Start Guide](Documentation/Rocket%20Slicer%20Quick%20Start%20Guide%20V1.3.0%202026-07-11.pdf)
- Hotend maintenance, unclogging, and part replacement guides
- Troubleshooting guides (first layer failures, layer shifting, etc.)

## 🧠 Knowledge Base

- [Error Code Reference](ERROR_CODES.md) — what the machine's error codes mean and how to resolve them
- Tips, workarounds, and hard-won knowledge live in the [wiki](../../wiki) and resolved [issues](../../issues?q=is%3Aissue+is%3Aclosed)

If you solve a problem that stumped you, consider sharing it — future owners will thank you.

## 🤝 Contributing

This project thrives on community contributions:

1. Check existing issues before opening a new one.
2. Share firmware version and machine details with every report.
3. Contribute fixes, guides, and knowledge back via pull requests or wiki edits.

## ⚠️ A Note on Firmware

Firmware files are **not hosted in this repository** due to their size. See [FIRMWARE.md](FIRMWARE.md) for an index of official firmware downloads and changelogs.
